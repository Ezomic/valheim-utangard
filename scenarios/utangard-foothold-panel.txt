# Utangard - the compendium page shows the biome you pick and your two bars there. LHM-26.
#
# What it proves. The compendium opens on the Utangard page drawn as a panel. Clicking Deep North
# in the biome strip shows "The Deep North", with the Fighting bar at the number the console
# prints and the Discovery bar at the number the console prints, each in its own box beside its
# own heading. The page keeps up while it is open: a change to the kill count shows within its
# one-second refresh without reopening it. Clicking the Meadows, which is open, shows that biome
# and takes the boxes away.
#
# The Fighting bar is seeded here, 7 Jotun warriors for 35, rather than fought. This is a test of
# what the page draws; utangard-foothold-eating is the test of how kills fill the bar.
#
# What it needs. A world you host, default Foothold settings, Presentation.ShowCompendiumPanel on,
# and the game in English, since the biome names are clicked and read by their English names.
# The Deep North is shut the way utangard-altar-in-a-locked-biome shuts it.
#
# What it leaves behind, and none of it can be undone:
#  - This character's kill count for every creature on the Deep North points line: 0 for all of
#    them except JotunWarrior, which is left at 8. The old numbers are not kept anywhere, and the
#    count lives in the character, so it follows it into every world. Use a throwaway character.
#  - The Deep North ground the run lands on is uncovered on this character's map of this world.
#  - Fader's records in this world stay cleared. `key defeated_fader` puts them back.

clear
god
ghost

unkey defeated_fader
unkey utangard_open_defeated_fader
unkey wither_open_defeated_fader
unkey utangard_first_defeated_fader
unkey utangard_p_$player_defeated_fader
wait 1

tally GoblinDeepNorth 0
tally Elaking 0
tally ElakingLantern 0
tally ElakingMole 0
tally DvergerDeepNorth 0
tally Moose 0
tally ShadowPerson 0
tally JotunWitch 0
tally JotunWarriorDualWield 0
tally Barka 0
tally JotunWarrior 7

# What the console says, so the page can be held to it.
biome DeepNorth 20
wait 3
console utangard foothold
until 180 Map counted.
printed DeepNorth (LOCKED, its rules apply to you now): fighting 35/100 (35%) yes
note pct DeepNorth \(LOCKED.*discovery \d+/\d+ px \((\d+)%

# The page, on the Deep North. It opens on the group's frontier, which on this world may be an
# earlier biome, so the Deep North is clicked either way.
compendium
wait 1
press Deep North
wait 1
panel The Deep North yes
beside Fighting | 35% yes
panel Eating at 50% yes
beside Discovery | $pct% yes
panel Healing needs both full yes

# One more warrior on the record while the page stays open.
tally JotunWarrior 8
wait 2
beside Fighting | 40% yes

# An open biome: its own name, and no bars.
press Meadows
wait 1
panel The Meadows yes
panel Eating at 50% no
close
